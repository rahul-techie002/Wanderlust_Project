# 🏡 Airbnb Clone

## 📌 Overview
This project is a full‑stack **Airbnb clone** built to demonstrate my ability to design, develop, and deploy modern web applications. It replicates core features of Airbnb, including property listings,functionality, authentication, 

The goal of this project is to showcase my skills in **frontend development, backend APIs, database design, and deployment practices**.



## 🚀 Features
- 🔐 **User Authentication** – Sign up, login, and secure sessions  
- 🏠 **Property Listings** – Add, edit, and browse available Listing  



## MVC Architechture
This project is an Airbnb clone built using the MVC architecture
that make code readable and provide modularity.
